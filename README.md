# Collab Free

Mod de Geode para Geometry Dash 2.2091: edita el mismo nivel con hasta 5 amigos en tiempo real, gratis.

- `mod/`: el código del mod (C++, Geode v6.0.0-alpha.2)
- `server/`: el servidor de salas (Node.js, sin dependencias)
- `.github/workflows/build.yml`: GitHub compila el mod solo y te da el `.geode`

**Lee `GUIA.md` para instalarlo paso a paso.**

Hecho para usarlo entre amigos. No está pensado para publicarse en el Geode Index.
